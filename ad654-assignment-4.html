R.

When using a logistic regression model to make predictions, why is it important to only use values within the range of the dataset used to build the model?

  • When the modeler tries to predict an outcome value using input variables outside the range of the dataset, this is referred to as extrapolation. The model only knows the relationships between the inputs and the outcome for the data that is sees during model fitting. The nature of that relationship may change at other ranges of values, so any model prediction based on extrapolated inputs would not be reliable.
