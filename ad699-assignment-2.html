Why is it important to partition the data before doing any sort of in-depth analysis of the variables?

  • If we build and test our model on the same dataset, it will perform unrealistically well because it has learned 'noise' instead of underlying patterns, this is called overfitting.

  • By using a training set, the model can learn new patterns anf then by evaluated on 'new', unseen data from the test set.

  • By analyzing all variables such as finding relationships, correlations and feature importance using the full dataset before splitting, the results will be unreliable as you're giving information from the test set into modeling decisions.

import statsmodels.api as sm
target_variable = training_set['income']
predictor_variables = training_set[['reports','age','expenditure','dependents','months','majorcards','active']]
predictor_variables = sm.add_constant(predictor_variables)
def backward_elimination(target_variable, predictor_variables, significance_level=0.05):

    X = predictor_variables.copy()
    y = target_variable
    while True:
        model = sm.OLS(y, sm.add_constant(X)).fit()
        p_values = model.pvalues.drop('const', errors='ignore')
        max_p_value = p_values.max()

        if max_p_value > significance_level:
            worst_var = p_values.idxmax()
            print(f"Removing '{worst_var}' (p = {max_p_value:.4f})")
            X = X.drop(columns=[worst_var])
        else:
            break
    final_model = sm.OLS(y, sm.add_constant(X)).fit()

    return final_model, X
final_model, final_predictors = backward_elimination(target_variable, predictor_variables.copy())
