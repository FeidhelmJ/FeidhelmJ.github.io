  1. Calculate the categorical cross-entropy (CCE) loss for the following multi-class classification problem. The true labels are one-hot encoded. For a single sample with C classes.
import torch
import torch.nn.functional as F
y_true = torch.tensor([
    [0, 1, 0],
    [1, 0, 0],
    [0, 0, 1]
], dtype=torch.float32)

y_pred = torch.tensor([
    [0.1, 0.8, 0.1],
    [0.7, 0.2, 0.1],
    [0.05, 0.05, 0.9]
], dtype=torch.float32)
y_true_idx = torch.argmax(y_true, dim=1)
loss = F.nll_loss(torch.log(y_pred + 1e-12), y_true_idx)
print("Categorical Cross-Entropy Loss:", round(loss.item(), 4))
Categorical Cross-Entropy Loss: 0.2284

Compared to the single decision tree (83.2% training, 64.6% validation), the random forest performed better overall, achieving higher accuracy on both datasets and demonstrating stronger generalization to unseen data. This improvement occurs because the random forest combines the predictions of many decision trees, reducing variance and mitigating overfitting.

Overall, the random forest performed well, balancing model complexity and accuracy, and confirming that using an ensemble of trees provides more robust and reliable yield predictions than a single decision tree.

Therefore, I would recommend the random forest model. It provides more consistent performance, better handles feature variability, and delivers stronger, more reliable predictions of college yield rates.
