Step 2 – Build a Fragility Metric

Create one metric of your own design that captures fragility.

Your metric must use at least two variables.

Examples:

● liabilities relative to liquid assets

● exposure concentration

● withdrawal coverage ratio

● leverage-adjusted loss exposure

Create a new column or computed value showing this metric.

Clearly state your formula.

To measure fragility, I created a Fragility Contribution metric for each asset. This metric combines the size of the asset, how much of it is usable for withdrawals, the haircut it would face under stress, and whether it is linked to affiliates. The formula is:

Fragility Contribution = Amount × (1 − Usable %) × (1 + Haircut %) × (1 + Affiliate Flag)

I chose this approach because fragility is not just about size, but about how reliable an asset is during a crisis. Assets that are illiquid, heavily discounted under stress, or tied to affiliates contribute more to overall fragility. Higher values of this metric indicate assets that are less dependable when the system is under pressure.

ftx["fragility_contribution"] = np.where(
    ftx["balance_type"] == "Asset",
    ftx["amount_usd_bil"]
    * (1 - ftx["usable_for_withdrawals_pct"] / 100)
    * (1 + ftx["stress_haircut_pct"] / 100)
    * (1 + ftx["affiliate_linked_flag"]),
    np.nan
)

# Sort most fragile assets

withdrawal_range = np.linspace(0, 1, 20)   # 0% → 100%
haircut_range = np.linspace(0, 0.5, 20)    # +0% → +50%

# Store results
heatmap = np.zeros((len(withdrawal_range), len(haircut_range)))

# Function to compute fragility under stress
def compute_fragility(df, withdrawal_shock, haircut_shock):

    temp = df.copy()

    # Adjust usability (higher withdrawals → less usable)
    temp["adjusted_usable"] = temp["usable_for_withdrawals_pct"] / 100 * (1 - withdrawal_shock)

    # Adjust haircut
    temp["adjusted_haircut"] = (temp["stress_haircut_pct"] / 100) + haircut_shock

    # Recompute fragility
    temp["fragility"] = np.where(
        temp["balance_type"] == "Asset",
        temp["amount_usd_bil"]
        * (1 - temp["adjusted_usable"])
        * (1 + temp["adjusted_haircut"])
        * (1 + temp["affiliate_linked_flag"]),
        0
    )

    return temp["fragility"].sum()
# Fill grid
for i, w in enumerate(withdrawal_range):
    for j, h in enumerate(haircut_range):
        heatmap[i, j] = compute_fragility(ftx, w, h)

# Plot heatmap
plt.figure()
plt.imshow(heatmap, origin="lower", aspect="auto")

plt.colorbar(label="Fragility Score")
plt.xlabel("Haircut Shock")
plt.ylabel("Withdrawal Shock")

plt.title("Stress Map: Fragility Across Scenarios")

plt.show()

Monte Carlo Simulation

Objective: Simulate many possible futures and observe how often the system fails.

Requirements

○ collateral impairment

○ a distribution plot (histogram or similar)

○ a failure probability estimate

# Separate assets and liabilities
assets = ftx[ftx["balance_type"] == "Asset"].copy()
liabilities = ftx[ftx["balance_type"] == "Liability"].copy()

# Total liabilities
total_liabilities = liabilities["amount_usd_bil"].sum()

# Number of simulations
n_sims = 5000

# Store results
liquidity_gaps = []
solvency_flags = []

for _ in range(n_sims):

    # Uncertain variable 1: withdrawal demand as % of liabilities
    withdrawal_pct = np.random.uniform(0.20, 1.00)

    # Uncertain variable 2: extra haircut shock added to existing haircut
    extra_haircut = np.random.uniform(0.00, 0.40)

    # Compute stressed usable asset value
    stressed_usable_assets = 0

    for _, row in assets.iterrows():
        usable_fraction = row["usable_for_withdrawals_pct"] / 100
        base_haircut = row["stress_haircut_pct"] / 100

        # Total haircut cannot exceed 100%
        total_haircut = min(base_haircut + extra_haircut, 1.0)

        stressed_value = row["amount_usd_bil"] * usable_fraction * (1 - total_haircut)
        stressed_usable_assets += stressed_value

    # Withdrawal demand in billions
    withdrawal_amount = withdrawal_pct * total_liabilities

    # Liquidity gap
    liquidity_gap = stressed_usable_assets - withdrawal_amount
    liquidity_gaps.append(liquidity_gap)

    # Failure if system cannot meet withdrawals
    solvency_flags.append(liquidity_gap >= 0)
# Convert to dataframe
mc_results = pd.DataFrame({
    "liquidity_gap": liquidity_gaps,
    "survives": solvency_flags
})

# Failure probability
failure_probability = (mc_results["survives"] == False).mean()

print("Estimated Failure Probability:", round(failure_probability * 100, 2), "%")
print("Average Liquidity Gap:", round(mc_results["liquidity_gap"].mean(), 3))

assets = ftx[ftx["balance_type"] == "Asset"].copy()

# Range of withdrawal %
withdrawal_range = np.linspace(0, 1, 50)

results = []

for w in withdrawal_range:

    stressed_assets = 0

    for _, row in assets.iterrows():
        usable = row["usable_for_withdrawals_pct"] / 100
        haircut = row["stress_haircut_pct"] / 100
